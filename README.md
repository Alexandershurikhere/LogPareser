# Spring Core Practice & Parser

Учебный проект для практического освоения ключевых концепций **Spring Framework Core** (IoC, Dependency Injection, управление жизненным циклом бинов) и работы с Java.

## 🛠 Технологии и стек
* **Java 17**
* **Spring Framework 6** (`spring-context`, `jakarta.annotation-api`)
* **Maven** (сборка проекта и управление зависимостями)
* **VS Code** (среда разработки)

## 📌 Ключевые изученные концепции Spring
В рамках проекта на практике отработаны:
* **Конфигурация через аннотации & XML**: сканирование компонентов (`<context:component-scan>`) и файловые свойства (`<context:property-placeholder>`).
* **Управление бинами**:
  * `@Component` — регистрация компонентов в IoC-контейнере.
  * `@Autowired` & `@Qualifier` — внедрение зависимостей и разрешение неоднозначностей при наличии нескольких реализаций интерфейса.
  * `@Value` — внедрение конфигурационных параметров из `.properties`.
* **Жизненный цикл бинов (Bean Lifecycle)**:
  * Использование `@PostConstruct` и `@PreDestroy` для настройки initialization/destruction хуков.
  * Разница в поведении жизненного цикла для областей видимости `@Scope("singleton")` и `@Scope("prototype")`.
